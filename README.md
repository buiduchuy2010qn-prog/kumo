# Kumo — Tai thỏ nhỏ gọn cho Windows 10 & 11

**Trang chủ & Demo tương tác trực tiếp:** [https://buiduchuy2010qn-prog.github.io/kumo/](https://buiduchuy2010qn-prog.github.io/kumo/)  
**Tải bản mới nhất (`KumoSetup-v*.exe`):** [GitHub Releases](https://github.com/buiduchuy2010qn-prog/kumo/releases/latest)

Kumo biến cạnh trên màn hình Windows 10 & Windows 11 (x64) thành một thanh tai thỏ đen nguyên bản sắc nét (`PerMonitorV2` + `ClearTypeGridFit`), đi kèm bảng quản lý nền sáng dịu mắt.

## Tính năng chính
- **Thanh bình thường & Thu nhỏ hiện Lời Nhạc**: Hiển thị vòng pin + đồng hồ khi nghỉ; khi phát nhạc trên Spotify, YouTube, Chrome/Edge tự hiện ảnh bìa thực cùng **lời bài hát đồng bộ trọn câu** (tự cuộn mượt câu dài, không cắt mất chữ).
- **Thanh trạng thái tải tệp & Microsoft Store**: Tự động báo dung lượng, tốc độ `MB/s` khi tải tệp trên trình duyệt (`.crdownload`, `.part`, `.opdownload`, `.download`) và phần trăm cài đặt ứng dụng từ Microsoft Store.
- **Tự né Tab trình duyệt (`Auto-Minimal`)**: Tự động thu mảnh còn `4.5px` khi cửa sổ phóng to chạm mép trên màn hình.
- **OSD Phần cứng & Theo dõi hệ thống**: Thanh âm lượng màu trắng, độ sáng, cảnh báo pin 3 trạng thái (`Đang sạc`, `Pin bình thường`, `Pin yếu`), theo dõi `CPU / RAM / SSD / Wi-Fi / GPU` thực, Pomodoro, nhắc uống nước, kệ tệp kéo-thả và ghi chú nhanh.
- **Gói gọn ~210 KB · Cài đè trực tiếp**: Cài đặt User-scope không cần quyền Admin (UAC); chạy bộ cài bản mới đè thẳng lên bản cũ đang mở mà không mất cài đặt hay dữ liệu.
